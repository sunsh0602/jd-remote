      추가 탭에서 넣은 링크가 여기에 담기고 유효성이 검증됩니다. 결과를 확인한 뒤 시작하세요.

      🧺 장바구니에 담기 — 장바구니에서 검증 결과를 확인하고, 원하는 항목만 골라 시작합니다.
      ⬇ 즉시 다운로드 — 장바구니를 거치지 않고 다운로드 목록에 넣습니다. 검증이 끝나면 자동으로 시작됩니다.

      호스터 계정

        등록된 계정이 없습니다.

        계정 추가

        TeraBox는 쿠키 로그인만 됩니다.
        PC 크롬에서 terabox.com 로그인 → "JD Remote 쿠키 도우미" 확장 아이콘을 누르면 자동으로 등록됩니다.
        수동으로 하려면 EditThisCookie (V3) 등으로 내보낸 쿠키를 아래에 붙여넣으세요.
        이메일은 TeraBox 로그인 이메일을 그대로.

        비밀번호/쿠키는 JD에 그대로 전달만 되고 이 앱에는 저장되지 않습니다.

        계정

        「쿠키 만료」가 실제로 봐야 할 날짜입니다. 넣어 둔 인증 쿠키 중 가장 먼저 만료되는 것 기준이며, JD는 쿠키를 스스로 갱신하지 못하므로 이날이 지나면 확장으로 다시 보내야 합니다.
        「다음 확인」은 구독 만료일이 아니라 JD가 계정을 재검증할 시각입니다. 매일 지나가며 쿠키가 살아 있으면 날짜만 뒤로 밀립니다.

        라벨(아이디)·쿠키 변경 — JD는 둘을 함께 받으므로 라벨을 바꿀 때도 쿠키를 다시 넣어야 합니다

        쿠키 로그인 계정입니다. 새로 내보낸 쿠키를 붙여넣거나, 확장 아이콘으로 자동 갱신하세요.
